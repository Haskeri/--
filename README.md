## Установка и запуск

```bash
# 1. Клонировать / перейти в папку
cd library

# 2. Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate      # macOS/Linux
# venv\Scripts\activate       # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить подключение к БД
cp .env.example .env
# отредактировать .env — указать реальные данные MySQL

# 5. Создать БД в MySQL
mysql -u root -p -e "CREATE DATABASE library_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 6. Инициализировать таблицы и тестовые данные
python init_db.py

# 7. Запустить
python run.py
# → http://localhost:5000
```

## Реализованный функционал

### Основной
- Каталог книг с пагинацией (10 книг/стр.), сортировка по году
- Просмотр карточки книги с обложкой, метаданными, рецензиями
- Добавление книги (только Администратор): загрузка обложки, Markdown-описание, дедупликация по MD5
- Редактирование книги (Администратор + Модератор)
- Удаление книги с подтверждением в модальном окне (только Администратор)
- Аутентификация: вход с «Запомнить меня», выход
- Разграничение прав: неаутентифицированные → редирект на логин, недостаточно прав → редирект на главную

### Вариант 1 — Модерация рецензий
- Три статуса рецензий: **На рассмотрении / Одобрена / Отклонена**
- Новые рецензии получают статус «На рассмотрении» автоматически
- На странице книги отображаются только **одобренные** рецензии
- Раздел **«Мои рецензии»** — для всех аутентифицированных пользователей: список своих рецензий с указанием статуса
- Раздел **«Модерация рецензий»** — для Модераторов и Администраторов: таблица рецензий «На рассмотрении» с пагинацией, кнопка «Рассмотреть» → страница с текстом рецензии, кнопки «Одобрить» и «Отклонить»
